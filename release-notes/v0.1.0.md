## OneWard VMS backend v0.1.0 — First release

This is the first working release of OneWard VMS. Point it at an RTSP camera,
call the REST API to start recording, and find chunked MP4 files on disk.

**Highlights**

- Continuous recording from RTSP cameras — H.264, H.265, MJPEG, and AV1 supported
- Automatic reconnection with exponential backoff (2 s → 60 s cap)
- Camera, source, and destination management via a full CRUD REST API (Salvo)
- AES-256-GCM credential encryption at rest; key loaded from `VMS_ENCRYPTION_KEY`
- SQLite out of the box; MySQL and PostgreSQL supported via the same migrations
- Single binary, Docker image, and `.deb` package for easy deployment
- Systemd unit with security hardening (`NoNewPrivileges`, `ProtectSystem=strict`,
  `ReadWritePaths=/var/lib/onward`)

No pipeline engine yet — automation, scheduling, and event-driven workflows are
coming in v0.2.0.
